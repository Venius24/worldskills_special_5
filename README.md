# Belle Croissant Lyonnais - Session 5
## Система управления промоакциями и программой лояльности (SQLite)

---

## 📋 Содержание проекта

Этот проект включает в себя:

1. **SQL схему базы данных SQLite** - создание таблиц Promotions и LoyaltyProgram
2. **Приложение управления промоакциями** - Session5_PromotionsApp.exe
3. **Приложение управления программой лояльности** - Session5_LoyaltyApp.exe

---

## 🚀 Быстрый старт

### Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

**Примечание:** SQLite встроен в Python, дополнительная установка не требуется!

### Шаг 2: Создание базы данных

**Автоматический способ (рекомендуется):**
```bash
python create_database.py
```

Этот скрипт:
- Создаст файл `belle_croissant.db`
- Выполнит SQL схему
- Добавит 12 тестовых промоакций
- Покажет статистику

**Ручной способ:**
```bash
sqlite3 belle_croissant.db < Session5_Database_Schema.sql
```

### Шаг 3: Инициализация данных программы лояльности

```bash
python initialize_loyalty_data.py
```

Этот скрипт:
- Добавит 500 клиентов в программу лояльности
- Начислит баллы 250 случайным клиентам (50-1500 баллов)

### Шаг 4: Проверка базы данных (опционально)

```bash
python verify_database.py
```

Или:
```bash
sqlite3 belle_croissant.db < Session5_DatabaseVerification.sql
```

## 📱 Функциональность приложений

### Session5_PromotionsApp.exe

**Основные функции:**
- ✅ Просмотр всех промоакций в таблице
- ✅ Добавление новых промоакций
- ✅ Редактирование существующих промоакций
- ✅ Удаление промоакций с подтверждением
- ✅ Множественный выбор применимых продуктов
- ✅ Настройка приоритетов промоакций

**Мастер разрешения конфликтов:**
- 📊 Шаг 1: Список всех конфликтов
- 🔍 Шаг 2: Детальное описание конфликта с временной шкалой
- ⚖️ Шаг 3: Изменение приоритета промоакции
- 🛠️ Шаг 4: Корректировка дат или удаление продуктов

### Session5_LoyaltyApp.exe

**Основные функции:**
- 👥 Список всех клиентов с пагинацией (10 на страницу)
- 🔍 Поиск клиентов по имени, ID или email
- 📊 Сортировка по различным параметрам
- ✏️ Ручное редактирование баллов лояльности
- 💾 Сохранение и отмена изменений

**Расчет баллов:**
- 🔄 Автоматический пересчет на основе истории заказов
- 📈 Многоуровневая система начисления:
  - Basic: 10 баллов за €10
  - Silver: 12 баллов за €10
  - Gold: 15 баллов за €10
- 🎂 +25 баллов в годовщину регистрации
- 🎉 +5 баллов за покупку в период промоакции
- 📋 Детальная разбивка начисления по каждому заказу

**Система вознаграждений (при 1000+ баллов):**
- 💰 Скидка 5€ на следующую покупку
- 🎫 Скидка 10% на следующую покупку
- ⭐ Повышение статуса (Basic → Silver → Gold)

**Автоматическое создание промоакций:**
- При выборе скидки создается персональная промоакция
- Высокий приоритет (99)
- Срок действия: 30 дней
- Применяется ко всем продуктам

## 🗄️ Структура базы данных (SQLite)

### Файл базы данных
- **Имя:** belle_croissant.db
- **Тип:** SQLite 3
- **Расположение:** Текущая директория приложения

### Таблица Promotions

| Поле | Тип | Описание |
|------|-----|----------|
| PromotionId | INTEGER | Уникальный ID (автоинкремент) |
| PromotionName | TEXT | Название промоакции |
| DiscountType | TEXT | percentage / fixed_amount |
| DiscountValue | REAL | Значение скидки |
| ApplicableProducts | TEXT | ID продуктов через запятую |
| StartDate | DATE | Дата начала |
| EndDate | DATE | Дата окончания |
| MinimumOrderValue | REAL | Мин. сумма заказа (опционально) |
| Priority | INTEGER | Приоритет (1-100) |

### Таблица LoyaltyProgram

| Поле | Тип | Описание |
|------|-----|----------|
| CustomerId | INTEGER | ID клиента (первичный ключ) |
| LoyaltyPoints | INTEGER | Баллы лояльности |
| MembershipStatus | TEXT | Basic / Silver / Gold |
| RegistrationDate | DATE | Дата регистрации |
| TotalSpending | REAL | Общая сумма покупок |
| LastUpdated | TIMESTAMP | Время последнего обновления |

## ⚠️ Важные замечания

### Преимущества SQLite

✅ **Не требует установки сервера** - встроен в Python  
✅ **Портативность** - вся БД в одном файле  
✅ **Нулевая конфигурация** - просто создайте файл  
✅ **Кроссплатформенность** - работает везде  
✅ **Простое резервное копирование** - скопируйте .db файл  

### Тестовые данные

Поскольку реальный API продуктов/заказов/клиентов недоступен, приложения используют **mock-данные**:

**Продукты (22 позиции):**
- Круассаны (классический, с шоколадом, с миндалем)
- Французская выпечка (багет, эклер, макарон, тарт)
- Десерты (профитроли, мильфей, наполеон)
- Кофе (эспрессо, капучино, латте, американо)

**Клиенты (500 человек):**
- Автоматически генерируются при инициализации
- Случайные даты регистрации (1 месяц - 3 года назад)
- Распределение по статусам: Basic, Silver, Gold

**Заказы:**
- Генерируются случайным образом для каждого клиента
- От 3 до 15 заказов на клиента
- Суммы заказов: €10 - €150

### Интеграция с реальным API

Для интеграции с реальным API необходимо:

1. **Обновить константу API_BASE_URL** в обоих приложениях
2. **Заменить mock-функции** на реальные HTTP запросы:
   - `get_mock_customers()` → GET `/api/customers`
   - `get_mock_orders(customer_id)` → GET `/api/orders?customer_id={id}`
   - `MOCK_PRODUCTS` → GET `/api/products`

3. **Добавить аутентификацию**, если требуется API

Пример замены:
```python
def get_real_customers():
    response = requests.get(f"{API_BASE_URL}/customers", 
                          headers={'Authorization': f'Bearer {TOKEN}'})
    return response.json()
```

## 🐛 Устранение неполадок

### Ошибка: Database file not found

```
Error: unable to open database file
```

**Решение:**
- Убедитесь, что файл `belle_croissant.db` находится в той же папке, что и приложение
- Запустите `python create_database.py` для создания БД

### Ошибка: Table doesn't exist

```
Error: no such table: Promotions
```

**Решение:**
```bash
python create_database.py
```

### База данных заблокирована

```
Error: database is locked
```

**Решение:**
- Закройте все приложения, использующие БД
- Закройте DB Browser for SQLite (если открыт)
- Перезапустите приложение

### Приложение не запускается

**Решение:**
```bash
# Проверьте установку зависимостей
pip install -r requirements.txt

# Проверьте наличие БД
python verify_database.py
```

### Особенности SQLite версии

- **Файловая БД**: Вся база в одном файле `belle_croissant.db`
- **Портативность**: Можно скопировать файл на другой компьютер
- **Простота**: Не нужно настраивать MySQL сервер
- **Встроенность**: SQLite входит в стандартную библиотеку Python
- **Резервное копирование**: Просто скопируйте .db файл

### Инструменты для работы с SQLite

**DB Browser for SQLite** (рекомендуется):
- Скачать: https://sqlitebrowser.org/
- Бесплатный, графический интерфейс
- Просмотр таблиц, выполнение запросов
- Редактирование данных

**Командная строка SQLite:**
```bash
# Открыть базу данных
sqlite3 belle_croissant.db

# Показать таблицы
.tables

# Показать структуру таблицы
.schema Promotions

# Выполнить запрос
SELECT * FROM Promotions LIMIT 5;

# Выход
.quit
```
